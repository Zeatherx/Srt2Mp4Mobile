# Srt2Mp4 Mobile

## What it is

An Android and iOS app that permanently adds SRT subtitles to MP4 videos.

## How it works

Choose a video and subtitle file, optionally translate the subtitles, then export. Processing stays on your device; translation models download on first use.

## Credits

- [Flutter](https://flutter.dev/) for the app framework
- [FFmpegKit](https://pub.dev/packages/ffmpeg_kit_flutter_new) for video processing
- [Google ML Kit](https://developers.google.com/ml-kit/language/translation) for on-device translation
